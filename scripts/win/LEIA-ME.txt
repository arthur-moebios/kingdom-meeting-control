Kingdom Meeting Control 0.2.0 — Windows / Zoom nativo
===================================================

Este pacote substitui a versão baseada no Chromium.
Instale o Zoom desktop e o JW Library antes de usar.

1. Execute KingdomMeetingControl.exe. O painel abre em uma janela do app.
2. Configure a reunião no painel. O Zoom desktop usa o login já realizado.
3. Configure o link Cloudflare e abra o PWA para controlar pelo celular.
   Informe um nome obrigatório para identificar o aparelho, sem código.
4. Importe os PDFs de programação por inteiro. Datas e nomes ficam no PC;
   a Sala B mantém cronômetros independentes no PWA.

Inclui Node, Python, Frida, pypdf, WebView2 e cloudflared.
Python e Chromium não precisam ser instalados separadamente.
Se necessário, instale o runtime Microsoft Edge WebView2 no Windows.

Os dados ficam em data-native, ao lado do executável. Ao atualizar uma
instalação existente, mantenha essa pasta e as configurações do Cloudflare.
Nenhum dado pessoal ou credencial do desenvolvedor acompanha o pacote.
O botão Iniciar com Windows configura a inicialização automática.
