# Windows 0.2.0

Substitui o instalador e o ZIP anteriores da release `pc-latest` pelo app de
Zoom desktop. O pacote contém Node, Python, Frida, pypdf, WebView2 e cloudflared,
sem Chromium, dados de reuniões ou credenciais locais.

- Compartilhamento automático da mídia do JW Library, áudio e otimização para vídeo.
- Painel Windows com câmera do anfitrião, ferramentas e layout ajustável.
- Cronômetros e nomes do salão principal sincronizados com o PWA.
- Sala B independente e vinculada à semana principal, exclusiva do PWA.
- Importação integral de PDFs, persistência de nomes por sala/data e exportação em imagem.
- Link fixo Cloudflare, PWA instalável, identificação obrigatória e revogação de aparelhos.
- Inicialização com Windows e integração da janela com o JW Library.

O workflow Windows compila o pacote nativo, testa os imports do Python incluído,
gera o instalador e substitui os arquivos da release atual. Os dados existentes
em `data-native` são preservados ao atualizar a mesma pasta de instalação.
